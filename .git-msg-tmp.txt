── 建立的规范 ──

docs/WORKSPACE-RULES.md（202 行）+ AGENTS.md 摘要：

  1. 构建产物不入库也不囤积 —— bin/obj 不进 git，但也不该留在磁盘
  2. 一次性实验目录当场删 —— 只放 .cs 与 .csproj，跑完删整个目录
  3. 截图进 %TEMP% —— 曾经散落 100+ 张验证截图
  4. backups 只留最近一份
  5. 研究/交接文档统一放 docs/research/ 并登记索引
  6. tools 只保留能构建的源码（7za / broker-setup / rescue / updater）

  健康标准：工作区 < 1 GB、tools < 50 MB、backups 1 个 zip、
           根目录 .md < 5 个、bin/obj 0 个
