# AAA协同跑图 v1.0.0

4 人协同跑**同一条**狗粮路线。不做占位，全员进入世界后一起跑，各采各的。

## 和「AAA狗粮联机团购」的区别

| | 团购脚本 | 本脚本 |
|---|---|---|
| 队伍结构 | 1P/2P/3P/4P 各跑一片 | 全员跑同一条 |
| 占位 | 需要（后执行/占位目录） | **不需要** |
| 换人 | 跑完踢人换下一个 | 不换，一起跑完 |
| mojang | 需要（重新上线） | **不需要** |

## 配置（全队必须一致的部分）

### 所有人都要填

**路线文件或文件夹**
填 BGI 路径配置目录下的相对路径，例如：
```
度假村/前执行
```
或单个文件：
```
度假村/前执行/624【收尾】纳塔-悠悠集市①-5.json
```

**队伍人数**：默认 4

**开跑前统一等待**：默认 8 秒。人齐后所有人等同样长时间再开跑，用来对齐起跑时机。网络快点可以调小。

### 房主填

**我的角色**：房主

**放人策略**：
- `白名单` —— 只放名单里的人（推荐）
- `无条件通过` —— 谁来都放

**白名单 1/2/3**：填队友的游戏名（有备注名的填备注名）

### 队员填

**我的角色**：队员

**房主的 UID**：房主的游戏 UID（个人资料页能看到）

**房主的游戏名**：用于确认进去的是对的人

## 白名单识别原理

房主按 Y 打开申请列表后，脚本会：

1. **模板匹配**：拿 `targets` 目录下的名字截图，在申请列表区域找
2. **OCR 兜底**：如果模板没匹配上，直接读文字

两个名字比对用编辑距离算相似度，所以截图文件名不必和白名单一字不差。

例如白名单填 `山客`，`targets` 里有 `山客.png` 就能匹配；文件名差一点（`山客0.png`）也能靠相似度对上。

### 添加白名单截图

```
targets/
├─ 山客.png
├─ 玄月.png
└─ 阿宴.png
```

截图方式：在游戏里打开好友/申请列表，截取**名字那一小块**。文件名用游戏里显示的名字。

> 以「备注」结尾的图片会被跳过（例如 `山客备注.png`）。

## 流程

### 房主

```
开世界
  ↓
循环按 Y 看申请
  ↓
白名单匹配 → 放行
  ↓
人数够了 → 等待 N 秒 → 开跑
```

### 队员

```
F2 → 搜房主 UID → 申请加入
  ↓
等待被放行（30 秒没反应就重试）
  ↓
进入后等其他队友
  ↓
满员 → 等待 N 秒 → 开跑
```

## 常见问题

**Q：为什么跑完不自动换人？**
本脚本设计就是全员一起跑完就结束。需要换人的话用团购脚本。

**Q：队员一直进不去？**
检查：
1. 房主 UID 填对没
2. 房主是否在线、是否关闭了联机
3. 房主是否开了「允许他人加入」

**Q：放人时识别不出队友？**
1. 检查 `targets` 目录有没有对应名字的截图
2. 截图区域是否准确（要截名字那一小块）
3. 看日志里 OCR 识别到了什么

**Q：人数一直数不对？**
左上角的 0P/1P/2P/3P/4P 标签会被鼠标遮挡，脚本已经自动移开鼠标。如果还不行，检查 `assets/RecognitionObject/` 下的 P 图标是否和当前游戏版本一致。
