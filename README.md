# SoulLink · 跨会话静默执行器

> 📌 **接手开发请先读 [HANDOFF.md](HANDOFF.md)** —— 里面是所有实测结论、1Remote RDP 实现要点、以及待办清单。

把原来那个「自动查找 ID 启动其他用户程序.bat」变成一个现代化玻璃卡片界面的桌面应用。
填一次配置，之后一条命令就能在**指定用户的桌面**上静默打开 / 关闭程序，全程无窗口、无弹窗。

> 界面风格：深空极光背景 + 磨砂玻璃卡片 + 霓虹渐变；原生 WPF 渲染，不依赖浏览器。

---

## 1. 它替你做了原来 bat 里的哪些事

原来的 bat：

```bat
set "TARGET=A2"                     ← 要手填用户名
set "PWD=12345678."                 ← 明文密码写在文件里
set "TARGET_EXE=...\BetterGI.exe"  ← 要手填程序路径
for /f ... query user               ← 自动找会话 ID
start "" "%PSEXEC%" -u %TARGET% -p %PWD% -i !SID! -d "%TARGET_EXE%"
```

现在：

| 原来 | 现在 |
| --- | --- |
| 手填用户名 | 界面里选/填一次，保存为账号 |
| 明文密码 | **DPAPI 加密**保存，命令行/日志里看不到 |
| 手填程序路径 | 「浏览」或「从运行中选择」 |
| 手动算会话 ID | 每次都自动 `query user` 查，断了重登也不用改 |
| 改 bat 改参数 | 一条命令：`SoulLink.exe close --action "A2 关闭 BetterGI"` |
| 要外部工具 | **不需要任何工具**，走 Windows 计划任务的 SYSTEM 身份投送 |

## 2. 快速开始

1. 双击 `SoulLink.exe`（会请求管理员权限，跨会话投送需要）。
2. 「启动台」→ 右上角 **新建**：
   - 用户名（例如 `a2`，不带域名）
   - 密码
   - 程序路径（例如 `D:\AAA挂机专区\A2\BetterGI\BetterGI.exe`）
   - 选择 **打开 / 关闭 / 重启**
   - 保存
3. 选中动作点「执行选中动作」，或直接复制底部那行命令。

右侧「在线会话」会实时列出当前登录的用户（每 6 秒自动刷新），点一下就能看/关它桌面里的进程。

### 启动参数：预设 + 自己填

「④ 启动参数」下拉里目前有三个选项：

| 预设 | 最终下发的参数 | 你要填的 |
| --- | --- | --- |
| 无参数（默认） | 什么都不加 | 不填 |
| **一条龙** | `--startOneDragon` + 你填的名字 | 只填配置名，例如 `启动`、`B线一条龙`；留空则按默认一条龙 |
| 自定义… | 你写的完整参数 | 整段参数 |

前缀 `--startOneDragon` 显示成绿色徽章，**由程序自动带上，不用手敲**，你只负责后面的名字。
这样原来 `D:\AAA挂机专区\A2\BetterGI\BetterGI.exe --startOneDragon 启动` 那条 bat 就变成：
选「一条龙」→ 名字填「启动」→ 完事。

实测中文路径 + 中文参数在目标会话里正常生效。
「关闭」动作不使用参数，选中关闭时参数区会自动变灰。

## 3. 命令行（保存后自动生成）

界面「启动台」底部、「命令行」页都能看到并一键复制：

```bat
:: 执行保存好的动作（最常用）
SoulLink.exe open  --action "A2 打开 BetterGI" --quiet
SoulLink.exe close --action "A2 关闭 BetterGI" --quiet

:: 临时指定，不用先建动作
SoulLink.exe open  --user a2 --exe "D:\AAA挂机专区\A2\BetterGI\BetterGI.exe"
SoulLink.exe close --user a2 --exe "D:\AAA挂机专区\A2\BetterGI\BetterGI.exe"
SoulLink.exe restart --user a2 --exe "D:\AAA挂机专区\A2\BetterGI\BetterGI.exe" --delay 5

:: 只看帮助
SoulLink.exe /?
```

退出码：`0` 成功 · `1` 执行失败 · `2` 参数错误 · `3` 目标账号没有登录会话。

### 无感说明

- 程序是 **WinExe**，双击/被调用都**不会出现控制台窗口**。
- 已经有一个 SoulLink 在托盘常驻时，新的调用会通过**命名管道**把命令转交给它，自己立刻退出（实测 3.7 秒左右完成一次跨会话启动）。
- 没有常驻时，会静默执行完再退出。
- 每次命令的结果都会追加到 `%LOCALAPPDATA%\SoulLink\last-command.log`，出问题直接看这个文件。

## 4. 界面

| 页面 | 作用 |
| --- | --- |
| 启动台 | 快捷动作列表 + 一键执行 + 生成的命令 + 实时在线会话 |
| **中控台** | **多用户标签页 + 内嵌 RDP 画面**，一个窗口里看管所有挂机会话 |
| 在线会话 | `query user` 的详细视图，可当面对话框里直接开程序、查看/结束进程 |
| 会话进程 | 选一个会话，看它桌面里跑着什么，可多选结束 |
| 命令行 | 命令速查 + 调试台（直接跑一条命令看结果） |
| 设置 | 投送通道状态、账号密码、行为开关、配置导入导出、运行日志 |

### 4.1 中控台（内嵌画面）

「在线会话」页选中一个用户 → **接入中控台画面**，就会在「中控台」页开一个标签，
里面是那个会话的**真实桌面**（RDP 内嵌，不是截图）。

- 顶部标签页切换不同用户，每个标签一块独立画面
- 「重连」重新连当前标签；「断开」只断画面，**目标会话继续挂机**
- 画面来自 RDP 客户端的真实渲染，可以直接用鼠标键盘操作

**账号设置**（设置 → 账号 → 「地址」）里有三个字段：

| 字段 | 说明 |
| --- | --- |
| 地址 | RDP 地址，例如 `127.0.0.3`。留空则自动探测 |
| 端口 | 默认 3389 |
| RDP 登录名 | 默认与 Windows 用户名相同，需要区分大小写时填这个（如 `A2`） |

> ⚠️ **环回地址不能按会话号推算。** 本机 RDP 在 `0.0.0.0` 监听，
> 所以 `127.0.0.1`~`.9` 端口都通，但只有部分能真正落到目标会话。
> 以 1Remote 里能连的那个地址为准（本机 a2 一直是 `127.0.0.3`）。

> ⚠️ **中控台要求主窗口是非分层窗口**，程序已自动处理。
> RDP 控件在 `AllowsTransparency=True` 的窗口里**画面会全黑**（HANDOFF 10.4）。

### 4.2 鼠标注入（转视角）

画面连上后会自动向目标会话投放一个注入代理，于是中控台里的鼠标动作真的会作用到那个会话：

中控台有两种输入模式，顶部按钮切换：

| 模式 | 行为 | 适合 |
| --- | --- | --- |
| **指针模式**（默认） | 绝对定位，可精确点击画面任意位置 | 点按钮、操作桌面 |
| **自由视角** | 光标隐藏锁在画面中心，移动即转视角 | 挂机游戏转视角 |

### 鼠标锁定

顶部按钮（或自定义热键）切换，逻辑只有两种状态：

| 状态 | 行为 |
| --- | --- |
| **未锁定**（默认） | 鼠标键盘**完全交给远端**，和直接开游戏窗口一模一样：点击、拖拽、右键、滚轮全部正常 |
| **锁定** | 光标固定在画面中心并隐藏，**移动即转视角**（可无限转），点击在当前位置生效 |

锁定后按**同一个热键**即可解锁。热键可自定义（点齿轮 → 「锁定热键」）：
默认 `Ctrl+Alt+Q`，支持 `Ctrl+Shift+F9` 这类写法，必须带修饰键。

锁定时可以单独调**灵敏度**（1.0x ~ 12.0x），设置自动保存。

> 🔒 **安全保证**：默认**不会**自动锁定；窗口失焦、最小化、切页面都会立刻释放；
> 即使其他路径都失效，热键也一定能解锁。系统「指针加速」在解锁后一定恢复原值。

### 4.3 不需要任何外部工具

投送进程改为 **SYSTEM 计划任务通道**（免安装，用完即删）：

```
schtasks /ru SYSTEM 拉起引导进程 → WTSQueryUserToken → CreateProcessAsUser
```

- 不需要外部工具、不需要装服务、不需要重启
- 密码不再出现在任何命令行里
- 一次投送约 **0.6~0.7 秒**

关闭窗口默认**最小化到托盘**（可在设置里关掉），托盘右键有「打开 / 执行上次动作 / 退出」。

## 5. 架构演进（验证记录）

在实测中确认了以下边界，供后续重构参考：

### 5.1 跨会话的两种手段

| 方案 | 结果 |
| --- | --- |
| 管理员令牌 + `WTSQueryUserToken` | ❌ 1314（不是 SYSTEM 就不行） |
| 管理员 + 窃取 SYSTEM 令牌 + 冒充 | ❌ 1314 |
| `CreateProcessWithTokenW` | ⚠️ 返回成功但进程落在**调用者会话**，是假成功 |
| **真 SYSTEM（服务或计划任务）+ CreateProcessAsUser** | ✅ 26–50ms，落点正确 |

结论：必须真正以 SYSTEM 运行。服务与计划任务权限等价，前者需安装、后者免安装。

### 5.2 会话隔离带来的限制

- 跨会话 **看不到** 目标会话的窗口（`EnumWindows` 返回 0 个）
- 跨会话 **截不到** 目标会话的画面
- 解决方式：把轻代理投进目标会话，由它采集后回传

### 5.3 输入注入

- 输入队列按会话隔离，在 a2 会话里注入鼠标**不会影响**前台用户的键鼠
- `SendInput` 在断开的 RDP 会话里返回 0（被拒）
- `mouse_event` / `SetCursorPos` 仍可用
- 但游戏靠 Raw Input 读**真实硬件**，合成输入多数被忽略 —— 想转游戏视角只能靠真实输入设备（串流）

### 5.4 串流性能基线（1280x720，a2 的 RDP 会话内实测）

| 质量 | fps | 抓屏 | 编码 | 单帧 | 带宽 |
| --- | --- | --- | --- | --- | --- |
| JPEG 50 | 31.7 | 29.1ms | 1.3ms | 32KB | 1.0 MB/s |
| JPEG 75 | 32.3 | 28.8ms | 1.0ms | 41KB | 1.3 MB/s |

瓶颈在 `CopyFromScreen`（约 29ms/帧），不在编码。若要 60fps 必须换 DXGI Desktop Duplication。

## 6. 安全

- 密码用 **Windows DPAPI（当前用户）** 加密后保存在 `config.json`，只有这台机器的这个 Windows 账号能解密。
- 密码用 DPAPI 加密存储，**全程不会进入任何命令行参数**，界面、日志、导出的文本里一律不出现明文。
- 投送走 Windows 计划任务的 SYSTEM 身份，一次性任务用完即删，不安装服务、不留残留。
- 需要管理员权限：跨会话投送与 RDP 画面注入必须提权。

## 7. 自己编译 / 重新打包

```bat
:: 直接双击 build.bat 也可以
dotnet build -c Release                        :: 轻量版：需要装 .NET 8 桌面运行时
dotnet publish -c Release -r win-x64 ^
  --self-contained true -p:PublishSingleFile=true ^
  -p:IncludeNativeLibrariesForSelfExtract=true ^
  -p:EnableCompressionInSingleFile=true ^
  -p:DebugType=none -o dist                    :: 单文件版：约 68MB，什么依赖都不用装
```

产物在 `dist\SoulLink.exe`。
编译时以嵌入资源打进 exe；运行时第一次使用会自动释放到 `%LOCALAPPDATA%\SoulLink\tools`。
程序不再依赖任何外部工具，`dist` 里除了 exe 不需要别的东西。

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示「找不到用户 xxx 的登录会话」 | 该账号没登录/已注销；让它登录后点「刷新」 |
| 提示「访问被拒绝」 | 没有以管理员身份运行 |
| 提示「登录失败 1326 / 用户名或密码不正确」 | 点「改密码」重新填 |
| 提示「需要管理员权限」 | 右键 SoulLink.exe →「以管理员身份运行」 |
| 命令执行了没反应 | 看 `%LOCALAPPDATA%\SoulLink\last-command.log` 与 `error.log` |
| 想恢复出厂 | 删掉 `%LOCALAPPDATA%\SoulLink\config.json` |

配置目录：`%LOCALAPPDATA%\SoulLink\`
（`config.json` 配置 · `state.json` 窗口状态 · `last-command.log` 命令结果 · `error.log` 异常 · `ipc.log` 管道调试）
