# SoulLink · 使用手册

> 版本 **3.2.0** ｜ 多用户挂机中控台
> 一个窗口管理本机所有 Windows 账号的挂机会话：内嵌画面、跨会话启动程序、自动化流程。

---

## 下载与更新

在 [GitHub Releases](https://github.com/xxwz77/SoulLink/releases) 下载 `SoulLink-版本-win-x64.zip`，解压后运行 `SoulLink.exe`。需要 .NET 11 Windows Desktop Runtime x64。首次从旧版更新时手动下载完整包，之后点击窗口中的版本号即可检查更新。

在 RDP 通用设置的录像选项下可开启网页远控。网页远控默认关闭。开启后，有观众时才启动直播，独立的录像设置继续生效。

## 1. 安装与启动

**系统要求**：Windows 10/11 64 位，已装 **.NET 11 桌面运行时**（没装的话双击 `check-runtime.ps1` 会自动引导安装）。

第一次运行：

1. 右键 `SoulLink.exe` → **以管理员身份运行**（跨会话操作必须提权）。
2. 程序启动后常驻托盘，关窗口默认最小化到托盘而不是退出。

**数据存放位置**：`SoulLink.exe` 同目录的 `data\` 文件夹（`config.json` 配置、各类 `.log` 运行日志）。

> 💡 整个 `data\` 文件夹就是你的全部数据。备份或换电脑时，连同它一起复制即可。

## 2. 第一次使用：三步跑起来

### 第一步：让要管理的账号登录

每个要挂机的 Windows 账号必须**已经登录**（RDP 或物理登录都行），注销或未登录的账号不会出现在会话列表里。

### 第二步：在中控台添加账号

1. 打开「中控台」页 → 左上角 **添加**。
2. 从在线会话里挑一个用户，填个显示名（比如 `A2`）。
3. 「RDP 地址」一般留空让它自动探测；多用户机器通常是 `127.0.0.3` 这类地址。
4. 保存。

### 第三步：建一个快捷动作

1. 打开「启动台」→ 右上角 **新建**。
2. 选账号 → 选程序路径（比如 `D:\挂机\A2\BetterGI\BetterGI.exe`）→ 选「打开」。
3. 保存，然后点「执行」。

搞定。之后就能在中控台里看它的画面，或者用自动化让它每天定时跑。

## 4. 启动台

日常用得最多的一页，分四块。

### 4.1 运行状态

顶部一排卡片，每个挂机账号一张，实时显示 BGI 是否在跑、配置组名、当前路线、今日报错次数、本次拾取数量。

状态灯颜色：

| 颜色 | 含义 |
|---|---|
| 🟢 绿 | 正在正常运行 |
| 🟡 黄 | 正在等待（比如等注入通道建立） |
| ⚪ 灰 | 没有运行 |
| 🔴 红 | 出错了，看下面的日志 |

### 4.2 快捷动作

「新建」一个动作 = **账号 + 程序路径 + 打开/关闭/重启**。

- **执行** —— 立刻执行一次
- **编辑** —— 改参数
- **删除** —— 删掉

动作可以附加**启动参数**：「一条龙」预设会自动带上 `--startOneDragon`，你只需要填一条龙的名字（比如 `启动`）。

### 4.3 自动化

点「为当前账号新建一个自动化流程」跳到流程编辑器，详见 [第 7 节](#7-自动化流程)。

### 4.4 在线会话 + 原始日志

右下角列出当前登录的所有会话，点一个就能看它的 **BetterGI 实时日志**（自动跟随滚动）。排查「为什么没跑」先看这里。

## 5. 中控台（内嵌画面）

一个窗口里同时看管多个账号，画面是**真实的 RDP 内嵌渲染**，不是截图，可以直接用鼠标键盘操作。

### 5.1 添加与排列

- 左上 **添加** → 从在线会话挑用户。
- 画面排列方式可选：单个 / 网格 / 多标签。
- 双击左侧用户列表可直接打开画面。

### 5.2 画面操作

| 按钮 | 作用 |
|---|---|
| 重新连接 | 重连当前画面 |
| **断开** | **只断开画面，目标会话继续挂机** —— 日常用这个 |
| 全屏 | `F11` 切换，`Esc` 退出全屏 |
| 注销 | 注销该用户并关闭其所有程序（**不可恢复**，慎用） |

### 5.3 键鼠接管（两种模式）

顶部按钮切换：

| 模式 | 行为 | 适合 |
|---|---|---|
| **指针模式**（默认） | 绝对定位，指哪点哪 | 点按钮、操作桌面 |
| **自由视角 / 锁定** | 光标隐藏锁在画面中心，移动即转视角（可无限转） | 挂机游戏转视角 |

**锁定热键**默认 `Ctrl+Alt+Q`，可在画面右上角齿轮里自定义（必须带修饰键，比如 `Ctrl+Shift+F9`）。按同一个热键解锁。

锁定时可单独调**灵敏度**（1.0x ~ 12.0x），自动保存。

> 🔒 **安全保证**：不会自动锁定；窗口失焦、最小化、切页面都会立刻释放；即使别的路径都失效，热键也一定能解锁。

### 5.4 连接设置

右侧「用户配置」里可以调色深（32/16/8 位）、缩放模式、性能等级、网络类型、音频输出位置、Windows 组合键发送方式、设备重定向（剪贴板 / 打印机 / 驱动器等，默认关闭）。

还有一项「连接前先把目标会话踢成断开」—— RDP 复用真实桌面的开关。

> ⚠️ 改了设备重定向类设置需要**重新连接画面**才生效。

## 7. 自动化（流程）

把「什么时候、做什么」画成流程图，程序按它自动执行。入口：启动台的自动化区。

### 7.1 三种节点

从左侧模块库拖到画布：

| 类型 | 数量 | 含义 |
|---|---|---|
| **条件** | 22 个模块 | 满足后才继续往下走 |
| **动作** | 14 个模块 | 条件满足后实际执行的操作 |
| **当天完成** | 1 个 | 到这里当天就不再重复跑 |

### 7.2 怎么连线

- **点起点，再点目标** 即可连线（双击空白处取消）。
- 一条线可以分叉到多个下游（全部执行）。
- 一个节点也可以被多个上游汇入。
- 想改「条件不满足时怎么办」：用条件节点自己的**取反**开关，而不是画第二条线。

### 7.3 状态灯不是说谎

| 颜色 | 含义 |
|---|---|
| 🟢 绿 | 条件满足，正在沿这条线往下走 |
| ⚪ 灰 | 条件不满足 |
| 🟡 黄 | 数据不可用（比如账号没绑定 BGI，读不到日志） |
| 🔴 红 | 动作执行失败 |

### 7.4 三种组合方式

- **全部满足**（AND）—— 所有条件都成立才继续
- **任一满足**（OR）—— 任意一个成立就继续
- **取反** —— 该条件不成立时才算满足

### 7.5 常用条件速查

| 条件 | 用途 |
|---|---|
| 定时·时刻 | 每天几点几分几秒触发（可设递增延时与复位周期） |
| 定时·间隔 | 每隔 N 秒触发一次 |
| 会话在线 | 目标账号的会话是否在线 |
| BGI 是否运行 / 日志活跃 | 判断 BGI 状态 |
| 配置组状态 | 某个配置组跑完了没 |
| 日志包含 / 日志缺失 / 日志有报错 | 按日志内容判断 |
| 进程检查 / 原神是否运行 | 某个进程在不在 |
| 时间段 | 只在某个时间段内执行 |
| 上一步结果 | 上一个动作成功还是失败 |

### 7.6 常用动作速查

| 动作 | 用途 |
|---|---|
| 启动 BGI / 停止 BGI | 开关 BetterGI |
| 执行一条龙 / 执行配置组 | 让 BGI 跑指定任务 |
| 关闭原神 | 关掉目标会话的 YuanShen.exe |
| 模拟按键 | 向目标会话发按键（支持组合键） |
| 鼠标点击 / 移动 / 滚轮 | 向目标会话发鼠标操作 |
| 打开程序 / 关闭进程 | 启动或结束指定程序 |
| 等待 | 暂停 N 秒（条件中断则重新计时） |
| 执行快捷动作 | 调用启动台里建好的动作 |
### 7.7 启动前的清场规则（重要）

**执行 BGI 相关动作前，程序会自动清场**，顺序固定：

1. 如果 BGI 正在运行，先按你配置的**「停止当前脚本」快捷键**
2. 等日志里出现这个按键 → 确认脚本停了
3. 关闭 BGI 进程
4. 确认进程全部退出
5. 才启动新任务

- **没配快捷键** → 直接关闭进程
- **按了键但 10 秒内没等到日志** → 直接关闭进程与游戏
- **勾选了「同时关闭原神」** → 只关**同一个会话**里的原神

> 💡 快捷键在 BGI 设置里配（通常是 `F12`），每个账号可以不同，程序读的是你实际配的那个键。

### 7.8 「立即运行一次」

编辑器右上角的「立即运行」按钮：**忽略定时条件**，立刻跑一遍。用来测试流程对不对，不影响正常的定时计划。

## 8. 远程管理

管理本机的 Windows 账户和 RDP 环境。

### 8.1 新增用户

右侧面板填：昵称（可留空）、Windows 用户名、密码（两次）。

可选勾选：

- **允许远程登录** —— 加入 Remote Desktop Users 组
- **管理员权限** —— 加入 administrators 组
- **密码永不过期**
- **登录界面隐藏**
- **同时创建 SoulLink 连接配置** —— 自动分配 `127.0.0.x` 地址

> 💡 表单没填完时，「创建用户」按钮是**灰色**的，点它会提示还差哪几项。

### 8.2 管理已有用户

左侧列表每行可以：

- **显示 / 隐藏** —— 登录界面是否可见
- **修改密码**
- **恢复 / 设置过期**
- **删除** —— 会删除用户配置文件，**不可恢复**

### 8.3 RDP Wrapper

多用户同时在线需要它。顶部显示状态（DLL 是否加载、服务是否运行）。

- **安装并重启** —— 一键安装/修复，**不需要重启电脑**
- **选择** —— 手动指定目录
- **恢复** —— 还原原始配置

## 9. 更新 BGI

批量给多个账号的 BetterGI 换新版本。

1. **更新包** → 选择 zip / 7z / rar / tar / gz（包里如果多一层 `BetterGI` 文件夹会自动识别）
2. 勾选**更新前备份 User 目录**（推荐，保留配置和脚本）
3. 在「选择要更新的账号」里勾上要更新的账号
4. 点**开始更新**

更新过程会**自动按清场规则停掉 BGI**（见 [7.7](#77-启动前的清场规则重要)），所以不必手动先关。

完成后点「打开备份目录」可以看历史备份，需要回档时直接找。

> ⚠️ 更新 BGI 时请**不要**同时手动操作 BGI。

## 10. 路线更新

更新 BGI 的路线库（`User\AutoPathing` 里的文件夹）。

**路线包来源**（二选一）：

- **云端更新源** —— 点「检查更新」看有没有新版本（不显示下载地址）
- **本地路线包** —— 直接选一个文件，优先于云端

**更新目标**：「从账号生成」会自动按已配置的账号 BGI 路径填入，也可手动「+ 添加」。

**定时更新**（程序运行期间生效）：每天指定时刻，或每隔几小时。

> 💡 「替换前把旧文件夹移入备份目录」建议保持勾选，出问题能一键还原。
> 包内第一层文件夹会**替换**目标里同名的文件夹，所以填的路径不要进到 AutoPathing 里面一层。

## 11. 联机大厅

多人一起挂机时，可以看到彼此的进度。

## 12. 会话瘦身

RDP 会话第一次登录会自动拉起一堆无关进程（浏览器、游戏栏、各种助手），实测单个会话能占 63~70 个进程、2.4~10 GB 内存。

1. 选择要处理的用户会话
2. 看「进程列表」里的进程构成
3. 勾选要清理的进程 → **结束进程**
4. 或者用「清理外围进程」一键处理已知白名单内的进程

**启动项优化**：只作用于下方**勾选**的账号，未勾选的完全不受影响。

> ⚠️ 清理前建议先看一遍列表。程序已排除有风险的进程（如 NVIDIA 容器、音频服务），但如果你有别的东西在跑，注意别误关。

## 13. 命令行

不开界面直接调用，适合放进计划任务或别的程序里。

```bat
:: 执行保存好的动作（最常用）
SoulLink.exe open  --action "A2 打开 BetterGI" --quiet
SoulLink.exe close --action "A2 关闭 BetterGI" --quiet

:: 临时指定，不用先建动作
SoulLink.exe open  --user A2 --exe "D:\挂机\A2\BetterGI\BetterGI.exe"

:: 只看帮助
SoulLink.exe /?
```

**退出码**：

| 码 | 含义 |
|---|---|
| 0 | 成功 |
| 1 | 执行失败 |
| 2 | 参数错误 |
| 3 | 目标账号没有登录会话 |

**特点**：

- 不会弹出控制台窗口
- 已有常驻实例时，新调用会**转交给它**，自己立刻退出
- 每次命令结果写进 `data\last-command.log`

> 💡 页面里的「命令调试台」可以直接试一条命令看效果，不用开别的窗口。

## 14. 设置

### 14.1 跨会话投送

「投送」= 让程序能在**指定用户的桌面**上启动程序。

| 方式 | 说明 |
|---|---|
| **SYSTEM 计划任务**（默认） | 免安装，用完即删，推荐 |
| SYSTEM Broker 管理员代理 | 常驻服务，适合频繁调用 |
| 手动代理模式 | 不自动投送，需自己导出并运行代理 |

点「重新检测」看当前通道状态；「安装 / 管理服务」切换 Broker 模式。

### 14.2 行为

| 开关 | 说明 |
|---|---|
| 关闭窗口时最小化到托盘 | 关掉就真的退出 |
| 允许命令行 / 其它程序调用 | 关掉后外部调用无效 |
| **仅管理挂机账号** | 全局隐藏主用户（只隐藏不删除数据） |
| 找不到会话时回退到当前用户 | 找不到目标会话时的兜底 |
| 界面动效（性能档位） | 高 / 中 / 低；挂机推荐「中」或「低」 |

> 💡 动效档位实测：动态背景约占 61 个单核百分点，呼吸灯约占 27 个。窗口失焦时动画会自动暂停，所以选「高」在后台也会自动降下来。

### 14.3 开机自启

用计划任务实现，只在指定 Windows 账户登录时启动，**不弹 UAC**。

- 勾「启用开机自启」→ 选启动账户 → 保存
- 「启动后自动连接」是**独立**的另一项，勾选即生效，与自启无关

### 14.4 BetterGI 路径

**只有在这里绑定过的账号才会被读取日志。**

未绑定的账号：完全不读文件，界面显示「BGI 未绑定」，自动化里也选不到。

- 点「从进程取」自动填入正在运行的 BetterGI
- 或直接输入路径后回车

### 14.5 配置文件与日志

- **打开数据目录** —— 就是 `data\` 文件夹
- **导出 / 导入配置** —— 换电脑时用
- **BGI 备份保留** / **路线包缓存保留** —— 可设上限，或点「立即清理」
- **运行日志** —— 最近 600 条实时显示

## 15. 常见问题

### 账号列表里看不到某个用户

该账号**没有登录**。注销或未登录的账号不会出现。让他登录后点「刷新」。

### 提示「需要管理员权限」

右键 `SoulLink.exe` → **以管理员身份运行**。

### 中控台画面全黑

1. 检查 RDP Wrapper 是否正常（远程管理页看状态）
2. 检查「RDP 地址」是否填对，多用户机器一般是 `127.0.0.3` 这类
3. 检查目标会话是否在线

### 自动化不执行

依次检查：

1. 流程是否**启用**（右上角开关）
2. 是否**暂停**了（暂停原因会显示）
3. 是否「今日已完成」—— 有「当天完成」节点的流程，跑过就不会再跑，到日界才重置
4. 只连了「手动」条件 → 必须点「立即运行」
5. 看「原始日志」里的具体报错

### BGI 相关动作一直失败

1. 设置里该账号**绑定 BetterGI 路径**了吗？
2. BGI 里配了「停止当前脚本」快捷键吗？（程序按你配的键去停脚本）
3. 看日志里有没有「等待注入通道」字样 —— 说明投送还没建立

### 密码忘了

远程管理页 → 找到该用户 → **修改密码**。

### 想恢复出厂设置

删掉 `data\config.json`（建议先备份整个 `data\` 文件夹）。

## 附：数据目录说明

```
data\
  config.json          配置（账号、动作、流程、设置）
  state.json           窗口状态
  last-command.log     每次命令行调用的结果
  error.log            异常记录
  rdp-debug-*.log      RDP 调试日志（按天分文件）
  boot.log             启动记录
```
