# 更新说明

## v4.0.0

- 桌面主界面支持高清主题、自定义背景裁切和卡片透明度设置。
- 概览可以按账号查看快捷动作与每日收益，并汇总所有会话的自动化执行状态。

- 概览分别记住运行日志和快捷动作两条分割线的位置，重启后按窗口高度恢复。
- 网页模板拾取支持按大类别、地区和颜色组合筛选，覆盖八个地区及通属地区。

## v3.3.94

- 「设置 → 外观」可实时调节主窗口卡片透明度，文字和图标保持清晰。自动化编辑器和独立弹窗保留各自样式。
- 「原图主题」可导入自己的背景、选取主题色，并在带卡片的预览中拖动或缩放取景。浅色、深色可分别设置。
- 16 套设计主题重绘了高清动态帧和静帧，适配高 DPI。切页及减少动态效果时按需解码。
- 概览刷新会拉取可用账号的最新摩拉流水并更新卡片。遇到授权失效、未选角色或请求失败时显示原因。月初和跨年继续按凌晨 4 点换日。

## v3.3.93

- 桌面各导航页共用所选主题的背景。切换至账号、自动化、数据中心和设置时可以继续看到原图或主题场景。
- 调整卡片透光度。关闭动态效果仍显示静态背景，窗口失焦或最小化时暂停动画。

## v3.3.92

- 概览中可上下拖动快捷动作与自动化之间的分隔线，分别调节右侧卡片和左侧日志的高度。
- 「光绫回声」加入沿掌心绸带向外飘散的青粉色粒子。

## v3.3.91

- 在概览中可拖动分隔线调整运行日志区域的高度。
- 用户列表增加「当前配置组」列，可直接查看各用户正在运行的配置组。
- 带 END 的自动化流程今日完成后，在概览中以金色按钮和状态灯显示。
- 标题栏版本号旁增加「更新说明」，可离线查看历次更新。

## v3.3.90

- 根据触发条件和动作自动为流程命名，也可自行修改名称。

## v3.3.89

- 首页会话卡片显示今日 A/B 线、狗粮经验、狗粮摩拉汇总和今日摩拉总收益。选择用户即可查看详情。
- 自动化「定时 · 时刻」支持每日、每周、每月、每年以及从起始日期每隔指定天数运行。
- 快捷动作的定时安排转由自动化管理，原有安排由程序迁移。
- 自动化编辑器支持切换流程所属用户，未保存的真实改动在关闭时才会提示。

## v3.3.88

- 调整桌面六套主题的背景和界面配色，改进不同主题下的控件可读性。

## v3.3.87

- 新增六套桌面主题，可分别记住亮色和暗色主题，也可跟随系统切换。
- 外观和性能设置分开，提供高、中、低三档，按需减少背景动效和界面动画。
- 总览可按用户切换运行日志，也可展开或折叠快捷动作和自动化操作区。

## v3.3.86

- 改善 BetterGI 运行日志和进度更新，延迟到达的摩拉记录按实际发生时间计入收益。
- 传送和联机切换后显示已确认的当前角色。折叠总览操作区时仍可查看会话状态。
- BetterGI 更新支持选择来源、浏览可下载版本及管理本地安装包。
- RDP 可区分轻按 Esc 与长按 Esc。

## v3.3.81

- 增加启动项清单，集中查看和管理 Windows 启动项。
- 改善数据中心摩拉收益归类和运行记录采集，并补充米游社签到设置。
- 桌面应用改从 GitHub Releases 检查更新，主程序与引擎组件可按各自版本更新。

## v3.3.51

- 修复数据中心角色查询阻塞界面和运行记录退出时的反馈问题。
- 减少退出 RDP 全屏时的重复布局。

## v3.3.50
