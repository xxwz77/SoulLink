# 更新说明

> 每次发版前修改下节内容，发布脚本会把它原样写进清单并显示在更新窗口里。

## 本次更新

- 修复网页远程控制松键释放、慢网络输入积压及相对移动小数丢失
- 修复冷启动视频首帧等待超过浏览器超时导致的反复重连
- 修复数据中心角色查询阻塞 UI、运行记录退出排空反馈不准确
- 减少退出 RDP 全屏时的重复布局

- 进入全屏不再弹出顶栏（顶栏是退出用的），画面一帧到位不再"顶部空一块"
- 修正全屏尺寸：隐形边框归零与物理像素定位的顺序问题，窗口精确贴合屏幕
- 退出全屏改为先恢复几何、再恢复窗口样式，消除位置跳两次
- 顶栏呼出更快：热区 12→24px、检测 120→60ms、自动隐藏 2→0.3 秒
- 修复退出全屏时重复重排导致卡顿的问题
- 全屏热键支持**鼠标键**（侧键、中键等）：原来只装了键盘钩子，录鼠标键会静默失效
- 修复自由视角切换后全屏热键失灵的问题（切换后重新挂载钩子）
- 修复救援程序 sl-rescue.exe 无法运行的问题（缺 dll 导致「应用程序不存在」）
- 退出全屏的备用热键**默认不再占用 Esc**（游戏里 Esc 是菜单键，被拦截会没法玩）
- 该备用热键改为完全可选：默认留空，需要时自己录一个，可一键清除
- 全屏退出菜单的鼠标热区从 6px 放宽到 12px，且不再要求窗口处于激活状态
- RDP 通用设置里可自定义「进入/退出全屏」和「退出全屏备用」两个热键
- 有新版本时，版本号旁直接显示「有新版本 vX.Y.Z」文字，不再只靠一个小圆点
- 检查更新改为每小时自动检查一次（原来只在启动时查一次，挂机久了看不到新版）
- 中控台新增 RDP 真全屏：F11 进入/退出，覆盖任务栏，画面放大铺满而非居中留边
- 全屏退出精确恢复原窗口位置与尺寸；切换页面自动退出全屏
- 发布方式改为全量包：避免跨版本更新时文件缺失，任何版本都能直接升到最新
- 新增《使用手册》（README.md），随包发布，各功能配图说明
- 远程管理页「创建用户」修复：表单未填完时按钮变灰，点击会提示还差哪几项
- 修复创建用户按钮无反馈、交互不明确的问题
- BGI 启动逻辑修正：不再读不到快捷键就拒绝启动，改为按需降级直接关闭
- BGI 停止当前脚本改为走投送通道优先，并用日志中出现的按键名确认已按下
- 修正停止脚本判定永远超时的问题（日志时间戳与基准的时区比较错误）
- 修正关闭 BGI 时可能误杀同会话中其它路径 BGI 进程的问题
- 更新 BGI 与自动化流程统一使用同一套清场逻辑
- 修正选「高（完整动效）」时背景只有静态图、画面不动的问题
- 修正打开设置页会把动效档位重置成「高」、覆盖原有设置的问题
- 挂机版窗口左上角增加「挂机版」标识，方便与主程序区分
- 修正更新程序在个别情况下无法替换主程序、需要手动重装的问题
- 修正更新提示窗口边缘出现黑边、圆角不完整的问题
- 修正点击版本号没有反应、无法检查更新的问题
- 会话瘦身：一键清理会话里与挂机无关的外围进程，可按账号单独控制
- 日志读取改由文件变化触发，状态响应从数十秒缩短到约 1 秒
- 修正设置里填了 BGI 路径却显示「未绑定」的问题
- 窗口最小化到托盘时不再刷新界面，降低常驻占用
- 会话查询改用系统原生接口，资源占用与响应速度明显改善
