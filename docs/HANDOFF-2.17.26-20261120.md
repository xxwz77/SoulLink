## 1. 用户反馈

> 「快捷动作的按钮还没改，也长的差不多。」

## 2. 原来长什么样

`Views/LaunchPage.xaml` 的快捷动作 `DataTemplate` 里，四个按钮**全部**是：

```xml
<Button Style="{StaticResource IconButton}" Width="30" Height="30">
```

同尺寸、同背景、同透明边框，只有图标不同。而且：

| 按钮 | 图标 | 语义 |
|---|---|---|
| 定时暂停/恢复 | `PauseGlyph` = `\uE769`(⏸) / `\uE768`(▶) | 管**定时计划** |
| 立即执行 | `\uE768`(▶) 写死 | **现在跑一次** |

**同一个 ▶ 图标同时表示"恢复定时"和"立即执行"** —— 这是最要命的一点，
用户完全无法判断按哪个会发生什么。

## 3. 本次改动

### 3.1 三档视觉层级（`Views/LaunchPage.xaml`）

| 按钮 | 外观 | 语义 |
|---|---|---|
| **定时开关** | 胶囊 + 文字：`⏸ 定时生效`（青绿）/ `▶ 定时已停`（灰），仅配了定时的动作才显示 | 持续状态 |
| **立即执行** | 胶囊 + 闪电 + 文字：`⚡ 执行`（中性色） | 一次性 |
| **编辑 / 删除** | 小图标，中性色；删除图标用偏红色 | 辅助操作 |

关键区别：
* 「定时开关」有**文字**（定时生效/定时已停）+ **状态色**，一眼看出是持续开关；
* 「立即执行」用**闪电图标**，与定时开关的 ⏸/▶ 不再撞车，且明确"不影响定时计划"；
* 删除按钮图标改偏红，避免误点。

### 3.2 ActionVm 新增绑定属性（`Views/LaunchPage.xaml.cs`）

`ScheduleToggleText` / `ScheduleToggleFg` / `ScheduleToggleBg` / `ScheduleToggleBorder`，
让「定时生效 / 定时已停」自带颜色，不依赖按钮模板（`PillButton` 的 hover 只改 Opacity，状态色不丢）。
