## 1. 用户要求

> 「鼠标xy，有点不方便，可以选择一张图片，在图片选择点击位置，

## 2. 设计要点：为什么存"比例"而不是"像素"

用户在截图上点的位置存成 **0~1 的归一化比例**（`pickX` / `pickY`），
而不是当场算出的像素值。原因：

* 目标分辨率可能变（换机器、改分辨率、窗口缩放）；
* 截图可能是 1080p，但实际会话是 4K；
* 同一张参照图应该能复用到所有分辨率。

运行期再用 `比例 × 目标会话实际分辨率` 换算，这才是真正的"自动计算"。
像素 x/y 仍然写回节点（供预览和其它地方读取），但不作为唯一依据。

## 3. 改动

### 3.1 新增参数类型 `FlowParamKind.CursorPick`（`Models/FlowNodeCatalog.cs`）

`ActMouseClick` / `ActMouseMove` 的参数改为：

| 参数 | 类型 | 说明 |
|---|---|---|
| `image` | **CursorPick** | 参照截图路径 + 图上点选 |
| `x` / `y` | Number | 由选点自动换算；也可手动微调（`required: false`） |
| `button` / `count` | 原样 | 点击键 / 次数 |

### 3.2 编辑器点选器（`Views/FlowEditorWindow.xaml.cs`）

```
[选择截图…] [清除选点]
┌────────────────────────────┐
│   截图预览（十字光标）       │
│        ○ ← 点这里标记        │
└────────────────────────────┘
将点击 (960, 540) ［按 1920×1080 换算］
```

* 「选择截图…」→ 打开文件对话框（png/jpg/bmp）；
* 在预览图上点一下 → 换算成比例存起来，并立刻显示换算后的像素坐标；
* 坐标提示会写明**按哪个分辨率换算**，用户能一眼看出对不对；
* 「清除选点」清掉选择位置（保留截图）。

### 3.3 目标分辨率来源

```csharp
var relay = RelayClient.FindBySession(state.SessionId);
return (relay.ScreenWidth, relay.ScreenHeight);   // 代理上报的真实分辨率
```

拿不到时兜底 `1920×1080`，并在界面上标注出来（不静默猜）。

### 3.4 运行期换算（`Services/FlowRunner.cs` `ResolvePoint`）

```csharp
double nx = a.GetDouble("pickX", -1), ny = a.GetDouble("pickY", -1);
if (nx >= 0 && nx <= 1 && ny >= 0 && ny <= 1)
{
    int rw = relay?.ScreenWidth ?? 0, rh = relay?.ScreenHeight ?? 0;
    if (rw <= 0 || rh <= 0) { rw = 1920; rh = 1080; }
    return (Clamp(nx * rw), Clamp(ny * rh));
}
return (a.GetInt("x", 960), a.GetInt("y", 540));   // 没配图 → 旧字段回退
```

`FlowNode` 新增 `GetDouble` / `SetDouble`，**固定用 InvariantCulture** ——
否则中文区域设置会把 `0.5` 写成 `0,5`，解析回来变成 0（这种坑很难查）。
