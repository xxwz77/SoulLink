## 0. 三条确诊 bug（P0-a 先修）

### Bug 1：铺满/等比没生效
- 根因：AndroidView modifier=Modifier.fillMaxSize() 强制撑满，AspectSurfaceView.onMeasure 等比收缩被吞（verifier 实证）+ setFixedSize 与 desiredAspectRatio 互斥（Moonlight Game.java:953-959）；
- **修法**：AndroidView modifier 改 wrapContentSize(Alignment.Center)；等比=默认（desiredAspectRatio=videoAspect），拉伸开关置 0。**验收：装机后横屏流在竖屏显示上下黑边（letterbox），中央无拉伸变形**。

### Bug 2：光标被 CURSOR_SHOWING 锁死
- 根因：visible=inside&&CURSOR_SHOWING（AgentWebServer.cs:765）→ 游戏全屏恒 false；if(cursorVisible) 永不画（PlayerPlaceholderScreen.kt:256，初值 false :90）；
- **修法**：客户端显式开关 shadowCursorEnabled（默认 true）——开时**无视 visible 常驻绘制**（位置仍用回传 nx/ny）。**验收：3D 游戏全屏（系统隐藏光标）时影子光标仍显示**。

### Bug 3：行走键=4 散落按键
- 根因：ControlsLayout.kt:53-56 k_w/k_a/k_s/k_d；Joystick 模型 :27 零预设使用；
- **修法**：fps/game3d 预设 WASD 换 VControl.Joystick（状态机已有：死区30%/粘滞150ms/回中KeyUp/切换防双键）。**验收：推左下 A+S 同亮（斜角双键），回中角色停走**。

## 一、三个组件边界（不可再混）

| 组件 | 职责 | 触发/默认 |
|---|---|---|
| 影子光标 | 显示远端指针位置（半透明箭头+videoRect 换算）| 常驻；显式开关（Bug2 修法），默认开 |
| 虚拟鼠标手柄 | **发鼠标输入**：拖=移光标（实体式一体）/弧瓣=左右键（按住+拖=拖拽）/顶圆=滚轮 | 菜单「虚拟鼠标」开关，**默认关**（占屏 25% 不宜常驻——用户要时开）|
| 虚拟摇杆 | 发 WASD（游戏行走）| 游戏模式（🎮）显示，桌面模式隐藏 |

★ 手柄默认**关**理由：控件直径 0.25 屏宽，桌面操作（单击/拖动=完整鼠标语义）已覆盖——手柄是**游戏/精准操作**的增强，非必需；向日葵也做成开关（v0194 实测开=用户自己开的）。

## 二、虚拟鼠标手柄交互规格（用户澄清定案）

```
        O   ← 滚轮（顶部圆，上下滑=Wheel）
     /     \
    (       )   ← 左弧=左键 / 右弧=右键
    (   o   )   ← 中圆=拖动区（拖=移光标，控件+光标一体移动）
     \     /
        ?   ← 底部⊖：[不确定]
```

| 操作 | 效果（=电脑操作）|
|---|---|
| 拖中圆 | 移动鼠标：控件跟随手指 + 光标按 delta 同步偏移（一体视觉，用户原话「自带光标指针，移动后点击就是点击位置」）|
| 点左弧 | 左键单击（在光标当前位置）|
| **按住左弧+拖** | **左键拖拽**：Down(left)→拖动期间 move→Up(left)（拖文件/选字唯一方式）|
| 点右弧 | 右键单击 |
| 滑顶部圆 | 滚轮（用户明确：「顶部我操作了好多次，是滚轮」）|

**控件本体 vs 光标**：拖中圆时**控件跟着手指走、光标同步偏移**（实体鼠标式——用户「自带光标指针」倾向）。[需装机实测微调：若控件跟手导致遮挡，改触摸板式（控件固定光标动）——留 P1 验证点]

**底部 ⊖**：[不确定]——用户未提；可能是收起/更多。实现先留空位不绑定功能，装机后问用户。

## 六、坐标体系（VideoTransform，verifier 公式）

三元组 scale/panX/panY；updateScale(ratio, focal)：scale*=ratio+clamp，焦点补偿 newPan=focal-(focal-oldPan)*newScale/oldScale；平移 pan+=中点位移 clamp [viewport-videoW*scale,0]；逆变换 nx=((screenX-panX)/scale-videoRect.left)/videoRect.width。
