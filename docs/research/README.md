  ★界面分工：主界面只显示「收尾A/B + 汇总」；数据中心页狗粮分区显示逐组三行表 + 合计。
  ★教训（§5）：① 改解析器后**不能靠「清库重扫」验证**——断点续传会跳过已读部分导致数据错乱（已从备份恢复）；② 多组共用解析器**必须逐组验证**；③ 「明细 + 合计」组合必须先确认两者互斥。
