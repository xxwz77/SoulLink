# t10 开发前勘察：90 个断言工程的真实成本（2026-11-24）

> 性质：**开发前勘察，不是正式开工**。只写了 `%TEMP%` 下的探针脚本，**未改产品代码、未碰 build.bat、未动 dist 与 artifacts**。
> 目的：回答「把 90 个断言串成闸门，真实成本是多少、该挂在哪」。

---

## 0. 结论（三个数）

| 问题 | 实测答案 |
|---|---|
| 全量 90 个跑一遍要多久（`-o %TEMP%`） | **99.7 秒（1.7 分钟）** |
| 全量 90 个（默认 bin，依赖完整） | **308.7 秒（5.1 分钟）** |
| 当前通过率 | **PASS 56 / RUN-FAIL 24 / BUILD-FAIL 10** |

### 决定性优化：`--no-dependencies` 把单工程从 7s 降到 0.8s

90 个里有 **53 个是 `ProjectReference ..\..\SoulLink.csproj`**——每个都会**重建整个 WPF 主工程**。
实测主工程**空转构建就要 7.6 秒**，所以那 53 个每个约 7 秒，且**增量也不省**（连续 4 个仍 6.8~7.9s）。

加 `--no-dependencies` 后：

```
  AgentNameCheck  --no-dependencies build = 0.8s  exit=0  exe=YES   (原本 7.2s)
  BrokerCheck     --no-dependencies build = 0.8s  exit=0  exe=YES   (原本 6.9s)
  AgentMutexCheck -p:BuildProjectReferences=false = 0.8s          (等价)
```

**代价**：`--no-dependencies` 只编译不复制依赖（`SoulLink.dll` 不进输出目录），
配 `-o %TEMP%` 时会 `FileNotFoundException` 假失败（0xE0434352）。**改用默认 `bin<name>` 目录即可**。

> 99.7s 与 308.7s 的差异来自输出目录：`-o %TEMP%` 快但缺依赖；默认 bin 慢但正确。
> **正式实现应用默认 bin + 增量**，实测 **5.1 分钟**。

- **5 个待查**（多为 ProjectReference 类）。

## 4. 闸门该挂哪里

| 方案 | 耗时 | 可行性 | 建议 |
|---|---|---|---|
| A. 挂每次 Release 构建（`AfterBuild`） | **5.1 分钟** | 太慢，毁掉迭代 | **不可行** |
| B. 挂 `build.bat` 末尾（发布前） | 5.1 分钟 | 可接受 | **推荐** |
| C. 独立 `run-assertions.ps1`，手动/发布前 | 5.1 分钟 | 最灵活 | **推荐（与 B 并存）** |
| D. 只跑 37 个 COMPILE-only（快闸门） | **~30 秒** | 快 | **推荐作为默认** |

**建议分层**：

1. **快闸门（默认）**：只跑 37 个 `Compile-only`（约 **30 秒**），挂 `build.bat`；
2. **全量（发布前）**：`run-assertions.ps1 -Full`，5.1 分钟，手动触发；
3. **CI/夜间**（若将来有）：全量。

关键：**必须先处理 34 个红的**（10 BUILD-FAIL + 24 RUN-FAIL），否则闸门一挂就是红的，
人会习惯性忽略——那就退化成「界面全绿但实际废了」的反面（**界面全红但没人看**）。

## 5. 顺带发现：一个反复踩的坑

勘察途中主工程**无法编译**，报 `CS0017 多个入口点`。根因：
`undefined\temp\soullink-t5-probe\Program.cs`（verifier 为 t5 建的探针，17:24）落在**项目根**下，
被 SDK 默认通配符收进编译；它自带 `Main`，与 `App.xaml.cs` 冲突。

**这与 `HANDOFF-20261124-39-AGENT-SPLIT-PENDING.md` §8 第 10 条是同一个坑**：
> 「临时实验目录绝不能建在项目根下（本轮踩过：`undefined\temp\agentver-probe\probe.cs` 被通配符编译进去，报 CS0017）」

上次是 `agentver-probe`，这次是 `soullink-t5-probe`——**同一个 `undefined\temp\` 路径，同一天第二次**。

Lead 已处理（移到 `%TEMP%`，内容保留）+ 计划加 `DefaultItemExcludes` 兜底。
**对 t10 的启示**：runner 自己生成的临时文件也绝不能落在项目根。
