## 1. 单击呼出菜单 = 错误

实测：tap 绑了 onTapToolbar，远端左键只能双击连发。
专业软件 100% 单击=远端左键（ToDesk/向日葵/RustDesk/Moonlight 一致）。
结论：呼出 = 顶部弧形页签菜单（照向日葵）常驻半透明点页签展开；tap 归还远端左键；三指下滑/顶部下滑保留补充。

## 2. 双指缩放 = 连续自由

Lead 的距离变化率区分思路正确（标准 pinch-zoom）。档位四钮删除。
实现：Compose detectTransformGestures 的 zoom 参数（乘法增量）乘当前 zoom，clamp 0.5~4.0；缩放中心 = 双指中点（非屏幕中心）。

## 3. 双指滑动 = 平移

RustDesk canvasModel.panX/panY。捏合模式下中点位移累加 panX/panY，clamp：pan ∈ [min(0,screenW-videoW*z), max(0,...)]（letterbox 吃掉平移空间）。

## 4. 等比没生效 = onFrame 没接（实测）

grep videoAspect：声明(:77)+消费(:169)，零写入。onFrame 从未设置 → desiredAspectRatio 恒 0 → 永远铺满。
修：H264Player.onFrame 接 videoAspect = w/h（一行）。onMeasure 收缩机制已在（StreamView 同款），缺数据。

## 5. 虚拟按键默认布局

向日葵 g019 实测：左圆形摇杆（底座约屏宽 10%、头约底座 40%、WASD 字标四方向）+ 右数字/技能/Shift 散落键。轮盘视觉 + 8 方向状态机（死区/粘滞/回中已实现），改视觉形态即可。

## 6. 行走键 = 轮盘

VControl.Joystick 状态机保留（死区/粘滞/回中已实现），视觉改「轮盘+WASD 字标」（W/A/S/D 显示在四方向位置）。改视觉不改逻辑。
## 7. 虚拟鼠标没显示（诊断）

按概率排序：
1. CursorEcho visible=inside（无 CURSOR_SHOWING）——服务端修复已在源码但 APK 未重装，用户测的是旧逻辑；
2. onCursor JSONObject 解析异常被吞（catch 静默）——需日志；
3. Canvas z 序被盖（光标层在工具栏之下）；
4. videoRect 全零 → NaN 不画（首帧 onGloballyPositioned 未触发）。
验证：装机后 logcat 加 videoRect/onCursor 临时日志。

## 9. 交互设计方案（最终形态，待审核）

### 9.1 常驻 UI（全部可见，无隐蔽手势）
- 顶部弧形页签菜单（输入/切换/编辑/设置/退出）：常驻半透明，点页签展开面板；
- 右侧图标列：模式 / 键盘 / 画面(等比拉伸缩放) / 更多 / 断开；
- 轮盘摇杆（游戏模式）：左下角，轮盘+WASD 字标，半透明；
- 影子光标：常驻（visible 驱动），箭头形态，按下变蓝。

### 9.2 手势语义（两套模式，对齐 RustDesk 指针/触控）
- 指针模式（默认，桌面）：tap=左键；拖动=move 绝对；长按=右键；双指=滚轮；
- 触控模式（游戏）：tap=左键；拖动=moverel 增量（轮盘语义）；双指=滚轮；
- 两套都：双击=远端双击；三指 tap=中键。

### 9.3 缩放
- 双指捏合 → 连续 zoom 0.5~4.0（乘法增量，中心=双指中点）；
- 双指同向滑 → pan（clamp 边界）；
- 双击（无缩放时）→ 远端双击；缩放中双击 → 复位。

### 9.4 键盘
- 完整遥控键盘（QWERTY+F1~F12+修饰键按住+组合键槽位+鼠标键+横向滚动）；
- 中文输入 → 系统 IME（Text 注入）；
- 键盘与 IME 二选一切换。

### 9.5 状态信息
- 右上角半透明小字（fps/延迟/码率），可开关（对齐 RustDesk Positioned top:10 right:10）。

## 10. 实施优先级（审核后做）
1. 顶部弧形页签菜单（替换隐蔽手势）——用户「找不到菜单」根治；
2. onFrame 接 videoAspect（一行，铺满/等比根治）；
3. 光标常驻 + 虚拟鼠标诊断日志（「没看见」定位）；
4. 轮盘摇杆视觉（WASD 字标）；
5. 连续缩放+平移（detectTransformGestures zoom/pan）；
6. 指针样式规整（保持 Path，调比例）。
