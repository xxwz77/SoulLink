# SoulLink 2.3.0

日期：2026-11-18

## 自动化流程

- 日界移到「每天完成」(END) 节点：00:00 / 04:00，节点属性内可选。
- 有 END：收尾后当天停止扫描；到 END 日界自动清除标记并开始新一轮。
- 无 END：不设日界，循环执行。
- END 节点属性新增双向开关「今天运行这个流程」：取消=今日不运行，勾选=恢复今日运行。
- 顶部状态条、END 今日状态、左下角校验行、启动台卡片统一显示「今日是否会运行」。
- 状态灯改为独立只读预览：校验失败或未保存的流程也会实时亮灭，且不写运行状态、不执行动作。
- 连线支持拖拽出口，以及依次点击起点/目标；出口端口放大。新节点自动避开重叠并滚动到可见处。

## 已知问题（本轮未修）

- 投送注入代理可能失败：CreateProcessAsUser 错误 740（需要提升）。原因：SYSTEM 计划任务启动带 requireAdministrator 清单的 SoulLink.exe，无法自动提升。
- 大厅在无房间码时设置空 FontFamily，导致未处理异常。
