怎么更新
═══════════════════════════════════════════════════

1. 关闭正在运行的 SoulLink（托盘图标右键退出）
2. 把 SoulLink.exe 复制到原来的目录，覆盖旧文件
3. 重新启动

配置不用搬：配置文件在
  %LOCALAPPDATA%SoulLinkconfig.json
升级不会动它，账号、动作、自动化流程都保留。


═══════════════════════════════════════════════════
这个版本有什么
═══════════════════════════════════════════════════

【新增】节点式自动化编辑器
  每个账号可以有自己的自动化流程，互不干扰。
  触发器(5种) → 条件(13种) → 执行器(18种) → 结束(1种)
  画布上拖节点、拉线连接，条件满足后自动执行。

【新增】条件状态记忆
  条件满足后就记住了，顺序无关。
  比如先满足条件3和2，再满足条件1，凑齐了才执行。
  退出流程才清零。可以在编辑器里关掉这个记忆。

【新增】进程/状态检查条件
  · 进程检查（能查其他用户的进程）
  · BGI 活跃状态（在跑 / 空闲 / 没运行）
  · 会话连接状态（在线 / 离线 / 无会话）
  · 数值比较（大于、小于、等于）
  · 上一步执行结果

【新增】更多执行器
  一条龙、配置组、打开程序、关闭进程、
  鼠标点击/移动/滚轮、模拟按键、等待、结束流程

【修复】日志读取慢
  A1 的日志有 33MB，原来每秒都要重扫一遍，界面卡。
  现在文件没变就直接用上次结果，有变化才读新增部分。

【修复】一直显示"等待日志信息"
  像"开始挖矿""动作：下落攻击"这类只报动作不报进度的任务，
  之前识别不了，现在能正确显示当前在做什么。

【修复】菜单反复开合
  鼠标放到分类上，菜单会稳定展开，不会闪。

【修复】关闭程序后流程还在跑
  现在关闭应用会立即中断正在执行的自动化。

出问题怎么办
═══════════════════════════════════════════════════

鼠标被锁住动不了：
  运行 sl-rescue.exe，它会强制解除锁定。

想回退到旧版：
  用你原来备份的 exe 覆盖回去即可，配置不用动。
